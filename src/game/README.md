# 文字格闘ゲーム Java練習プロジェクト

## 概要

Javaの基礎文法からオブジェクト指向設計までを網羅した総合練習として作成したコンソール型文字格闘ゲームです。

## 実行環境

- Java 16 以上

## 主な機能

1. ユーザーアカウントシステム：新規登録、ログイン認証、パスワード誤り回数制限
2. キャラクター成長システム：プレイヤーと敵で異なる成長ルール
3. ターン制戦闘システム：攻撃・防御・スキルの基本的な戦闘ロジック
4. コンソールUIユーティリティ：タイトル中央表示、罫線描画、入力正規化

## 学習ポイント

- カプセル化・継承・ポリモーフィズム（多態性）
- 列挙型（enum）による定数管理
- パッケージ階層による責務分離
- 単一責任の原則に基づくモジュール設計
- ユーザーシステムとゲームシステムの結合度を下げる設計

## 起動方法

1. リポジトリをクローン
2. `src` ディレクトリをソースルートとしてコンパイル
3. `game.App` をメインクラスとして実行
